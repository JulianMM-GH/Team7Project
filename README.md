# Perspicere

Perspicere follows a little boy whose life was once warm and full of joy, spent playing in the forest near his home, until it suddenly stopped.
One night, a light he almost recognises lures him outside and into a forest that looks strangely familiar.
As he follows it deeper, he must solve puzzles and collaborate.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites

* **Unity Hub** installed.
* **Unity Editor Version 6000.0.80f1** You can install it via Unity Hub.
* **Git** (for cloning the repository).
* An IDE for C# (like **Visual Studio** or **Visual Studio Code** with Unity integration).

### Installation

1.  **Clone the repository:**
    https://github.com/JulianMM-GH/Team7Project

2.  **Open the project in Unity Hub:**
    * Launch Unity Hub.
    * Click "Open" or "Add project from disk".
    * Navigate to the cloned `Team7Project` folder and select it.

3.  **Open the project in the Unity Editor:**
    * Once added, click on the project name in Unity Hub to open it in the Unity Editor.
    * Unity will import assets and compile scripts. This might take a few minutes the first time.

4.  **Open scenes:**
    * Once the editor is open, locate the Scenes folder in the Project window and double-click a scene to open it.

## ✨ Features

This project includes the following main game features:

• Two-player co-op built around the boy and the phoenix working together 

• Platforming with wall jumping 

• Pressure plates that open doors 

• Bells that make plants retreat and clear the way 

• The phoenix's aura, which reveals hidden platforms 

• A slingshot that lets the boy ring bells from a distance 

• Fire a shot through the aura to ignite it and burn walls down 

• A story told through a forest that slowly becomes familiar

## 🛠️ Usage

After installation and opening the project in Unity:

Press the Play button in the Unity Editor to run the game, typically starting from the `MainMenu.unity` scene.

Key scene files include:

* `Assets/Scenes/MainMenu.unity`: Main menu and start screen.
* `Assets/Scenes/Greybox1.unity`: Main gameplay scene.

Select GameObjects in the Hierarchy to view and modify their properties in the Inspector window.
